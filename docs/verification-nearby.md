### 杀进程恢复

经典玩法和血流分别验证：

1. 在客机的决策窗口杀掉客机进程，房主显示其离线。
2. 默认关闭托管时动作日志不增长。
3. 房主在牌桌管理中开启托管，AI 接手后动作日志增长；再次关闭托管。
4. 客机重新打开 App，恢复到原来的座位与恢复凭据。
5. 在局中杀掉房主进程，再打开并恢复房间。
6. 核对房主证书指纹、监听端口、固定牌墙 / 骰子 / 开局积分不变，动作日志接续，客机重连原房间。

传统规则的重放还逐座比较恢复前后的完整私有视图、手牌、牌墙余量和当前玩家；血流对比实际引擎恢复后的玩家与牌墙。恢复中的中间局面不会下发。

## 实体设备补验范围

自动化验证了二维码图片和内置离线解码器的往返，以及真实原生网络；尚未用两台实体手机完成镜头扫码、不同厂商热点 / 省电策略的验收。此版本面向同一 Wi-Fi 或热点，不提供公网中继或房主迁移。

正式 APK 位于 `artifacts/android/mahjong-1.3.0.apk`，对应 SHA-256 与构建来源记录位于同目录；签名沿用现有发布证书。
