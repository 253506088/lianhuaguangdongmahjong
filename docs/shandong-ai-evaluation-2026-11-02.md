# 山东AI第一轮弃牌优化

在规则与回放修复提交 `62a00d1` 已推送后，单独改进普通AI的弃牌评估。吃碰杠策略和随机明搂策略沿用原实现，这一轮不改变规则。

## 行为变化

- 每种弃牌只计算一次，先比较向听，再比较能降低向听的未知牌张数；用原结构偏好处理平手。
- 可听时按公开信息下尚未出现的张数选听口，避免为多听一种已经耗尽的牌放弃活听。全部听口均已公开耗尽时不主动报听锁手。
- 结构估值区分258将、乱将，支持山东四张同牌计两对的豪华七对、十三幺和十三不靠。风一色的听牌判断直接走正式规则；所有报听最终仍由正式规则确认。
- 只把自己的手牌、牌河、副露、明搂公开手牌及杠头传给AI；未知牌墙和他家暗手不进入决策上下文。未知张数包含他家暗手，不等于真实牌墙余张。
- 结构估值缓存只存纯牌型和将牌规则，限制12000项；公开余张每次重新计算，不复用过期场面信息。

## 固定牌墙试验

基线为 `62a00d1` 的普通AI。独立LCG种子20261102生成样本；每种规则12副144张牌墙，先跑全基线，再让一名新AI轮换四个座位对三名基线AI，共48个座位对照。两版本共同的随机明搂在试验中关闭，以隔离弃牌变化；正式游戏未关闭。

| 规则 | 基线胡牌次数 | 新AI胡牌次数 | 基线累计净分 | 新AI累计净分 |
| --- | ---: | ---: | ---: | ---: |
| 258 | 12/48 | 15/48 | 0 | +1300 |
| 乱将 | 12/48 | 14/48 | 0 | +480 |

基线净分为0是因为每副牌墙把四个座位都纳入对照。小样本结果只表明这一批固定牌墙表现改善，不证明长期胜率或所有对手下的优势。

## 计算成本

每种规则190副随机14张手牌，先热身10副；同一手牌交替测基线与新实现。最终回归同时运行时的本机测量如下，CPU争用会影响绝对数字：

| 规则 | 基线中位数/P95 | 新AI中位数/P95 |
| --- | --- | --- |
| 258 | 2.95 / 5.43 ms | 4.64 / 9.18 ms |
| 乱将 | 6.41 / 10.13 ms | 6.52 / 15.51 ms |

较空闲时同一批输入的新AI中位数约3–4ms。新版本提供更多牌效评估，258计算成本有所增加；不能把这轮称为纯性能提速。先以牌力改进为目标，手机耗时、吃碰选择、防守与明搂收益可后续分别评估。

## 复现与回归

运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/benchmark-shandong-ai.ps1`，脚本从Git读取基线，在 `tmp/shandong-ai-bench/` 生成历史代码和原始JSON。基准用例保留在 `tests/bench/`，不加入日常 `src` 单测，不把胜率样本写成易波动的自动门槛。

正式回归覆盖活听/死听、合法弃牌索引、258及乱将、豪华七对、十三幺、不同副露数量下不漏标准听牌，以及AI视角不含暗牌。全量2374项通过、2项跳过；山东规则与整场回放专项68项通过，包含258/乱将逐帧144张守恒与导出导入。类型检查、H5/Android网页构建及H5开局到回放的浏览器回归通过。
