# 山东麻将规则修复、默认入口与回放接入

H5 和 Android 共用的 App 每次启动优先选择山东麻将，大厅仍允许手动切换。附近同桌创建房间的默认规则也改为山东，258/乱将与可吃/不可吃继续保存用户选择。

## 规则与操作

- 点炮、抢杠采用包含外来胡牌的副本算番，实体牌仍保留原归属，144张牌数守恒。例：123456789万、123筒、5条，点炮5条，按1花×一条龙4×门清2×底分10结算80分；不再因少一张牌退回10分。
- 真人声明报听/明搂时校验实际弃牌，非法选择保留操作机会；再次点击声明按钮取消，新局清理待声明状态。引擎再次验证控制器动作，拒绝假听、锁手后换牌和非法胡杠。
- 抢杠请求带上报听状态。点炮/抢杠按座次依次询问，首位接受者单响；放弃者进入过胡锁定。
- 锁手后摸第14张仍显示原听口，隐藏不可执行的杠选项，结算后禁用明搂。
- 地胡在庄家未开杠的首张弃牌触发，无需报听，沿用原有固定25倍、三家各付一份的收付。天胡固定30倍。地胡来源仍为弃牌，不当作赢家已持有的牌。
- 海底按最后一张可正常摸取的牌判断，保留杠头；正常摸牌的补花延续这一判断，杠后补牌不算海底。八张花牌立即成胡能进入合法算番，起手集齐也能结算。
- 规则面板跟随258/乱将、可吃配置；规则面板和牌桌均展示实际底分10。
- 单机结算后牌桌增加退出入口，已完成的局正常收尾保存后可回大厅查看回放。

## 回放

`useShandongGame` 接受通用 `ReplayRecorderHooks`，在发牌补花完成后的锚点、每次摸打、吃碰杠胡、报听/明搂和结算处记录。

保存山东规则配置、完整初始牌墙、公开杠头、摸牌来源、声明状态、各动作后手牌/副露/牌河，以及逐项结算。空癞子列表保持为空；不会套用白板癞子。

回放投影还原明搂亮牌、报听状态、杠头和规则文案；局末补齐点炮/抢杠/地胡的外来和牌（即便原手牌已有同种牌）；结果提示采用实际总收入，不再一律把点炮分乘三。

牌谱格式升级为v2；v1记录继续读取和导入，原场次的录制版本保留，重新导出的文件封装使用当前版本。数据继续存本机IndexedDB，不引入新服务。
