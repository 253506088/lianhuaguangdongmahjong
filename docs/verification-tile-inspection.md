# 未知张数查询与 Android 1.2.0 验收（2026-11-01）

## 功能范围

- 本家手牌只查看同花色相邻一张和自身：七条 → 六、七、八条；一万 → 一、二万；九筒 → 八、九筒；字牌只显示自身。
- 点击牌河弃牌、他人副露或明楼牌，只显示点击牌自身。3D 使用实际实例射线拾取，牌背和未明楼暗手不提供查询。
- 已知数量包含自己的手牌、四家弃牌、四家副露、他人明楼手牌和公开杠头。每种普通牌的未知数量为四张减去已知数量，最低为零；不会读取牌墙或他人暗手计算答案。
- 支持非本家回合、报听锁牌后的查看，以及计数随场面更新。触屏保留轻触选牌、双击和上滑出牌；桌面保留悬停查看、单击出牌。点空白或 Esc 收起提示。
- 提示有牌面、牌名和数字，当前牌描边，零张突出显示；防止小屏边缘裁切。手牌透明区域不拦截公开牌点击，窄横屏头像上移以露出首张手牌。
